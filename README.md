# Sentiment Analysis Web App

This project analyzes the sentiment of user-entered text and classifies it as positive, negative, or neutral using NLP techniques.

## Tech Stack
- Python
- NLTK (VADER)
- Streamlit

## Features
- Text preprocessing
- Rule-based sentiment analysis
- Interactive web interface

## Learning Outcomes
- Understood NLP preprocessing pipelines
- Worked with rule-based sentiment analyzers
- Built a simple web application

## How to Run
pip install -r requirements.txt  
streamlit run app.py
